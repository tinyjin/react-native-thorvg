The classes, enums and their methods are the [`@thorvg/webcanvas` API](https://thorvg.github.io/thorvg.web/). This page covers React Native specific APIs.

:::note
This package follows `@thorvg/webcanvas` <WebCanvasVersion />. The WebCanvas reference describes the latest release, which can include APIs that <WebCanvasVersion /> does not have yet.
:::

## `useThorVG(options?)`

```ts
function useThorVG(options?: InitOptions): ThorVG | null;
```

Returns `null` until ThorVG is initialized and the ThorVG namespace afterwards. Initialization errors are thrown during render, so an error boundary can catch them.

## `init(options?)`

```ts
function init(options?: InitOptions): Promise<ThorVG>;
```

Initializes ThorVG outside of React. `init()` and `useThorVG()` share one initialization. Only the options of the first call apply, as in WebCanvas.

### `InitOptions`

| Option | Platforms | Description |
| --- | --- | --- |
| `renderer` | All | `'sw'`, `'gl'` or `'wg'`. See [Platforms](./platforms) for what each platform supports |
| `onError` | All | Receives errors instead of throwing them. See [Errors](#errors) |
| `locateFile` | Web | Resolves the URL of `thorvg.wasm`. Defaults to unpkg |
| `threads` | Web | Worker thread count for the threaded WebCanvas build |

## `ThorVG`

The namespace returned by `init()` and `useThorVG()`. It is the WebCanvas namespace without `Video`. `TVG.Canvas` takes the [`Canvas`](#canvas) view as its target.

## `Canvas`

```tsx
import { Canvas } from '@thorvg/react-native-thorvg';

<Canvas ref={view} style={{ width: '100%', aspectRatio: 1 }} />
```

The view a `TVG.Canvas` draws into. With children, it draws [components](./components/overview) instead, and takes the `TVG.Canvas` options below as props.

| Prop | Description |
| --- | --- |
| `ref` | Receives the view to pass to `TVG.Canvas`. Its type is `Canvas` |
| `androidBackingView` | `'TextureView'` (default) or `'SurfaceView'`. Android only |

All other `View` props, such as `style`, `onLayout` and the responder props, are passed to the view.

`ref.current.canvas` is the `TVG.Canvas` drawing into the view, or `null` before one is created.

## `TVG.Canvas`

```ts
const canvas = new TVG.Canvas(view, { width: 600, height: 600 });
```

The WebCanvas [`Canvas`](https://thorvg.github.io/thorvg.web/classes/Canvas.html) class. The target is the `Canvas` view ref. On web it also accepts a selector, an `HTMLCanvasElement` or an `OffscreenCanvas`, as in WebCanvas.

| Option | Description |
| --- | --- |
| `width`, `height` | Drawing size. Defaults to the layout size of the view and follows it |
| `enableDevicePixelRatio` | Renders at the device pixel ratio. Default `true` |
| `engineOption` | `TVG.EngineOption` value for the engine |

Call `destroy()` when the canvas is no longer used. See [Canvas](./guides/canvas) for sizing and lifecycle.

## Errors

ThorVG calls that fail throw a [`ThorVGError`](https://thorvg.github.io/thorvg.web/classes/ThorVGError.html) with a [`ThorVGResultCode`](https://thorvg.github.io/thorvg.web/enums/ThorVGResultCode.html). With `onError`, the error is passed to the handler instead:

```ts
useThorVG({
  onError: (error, context) => console.warn(context.operation, error.message),
});
```

`ThorVGError` and `ThorVGResultCode` are exported from the package.

## Types

The package re-exports the WebCanvas types, so you can import them from `@thorvg/react-native-thorvg`:

```ts
import type { Canvas, Shape, Picture, LottieAnimation, ColorStop } from '@thorvg/react-native-thorvg';
```

It also exports `ThorVG`, `InitOptions`, `CanvasProps` and `AndroidBackingView`.
