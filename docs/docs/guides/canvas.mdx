The `Canvas` component renders a native view on Android and iOS and a `<canvas>` element on web. `new TVG.Canvas(view, options)` creates a ThorVG canvas on it.

```tsx
const view = useRef<Canvas>(null);

useEffect(() => {
  if (!TVG) return;
  const canvas = new TVG.Canvas(view, { width: 600, height: 600 });
  // draw
  return () => canvas.destroy();
}, [TVG]);

return <Canvas ref={view} />;
```

`TVG.Canvas` is the WebCanvas [`Canvas`](https://thorvg.github.io/thorvg.web/classes/Canvas.html) class with the `Canvas` view ref as its target. It has the same methods: `add`, `remove`, `clear`, `update`, `render`, `resize`, `viewport` and `destroy`, plus the `renderer` and `dpr` getters.

## Drawing size and view size

Two sizes are involved, and they are independent.

| | Set by | Meaning |
| --- | --- | --- |
| Drawing size | `width` and `height` options of `TVG.Canvas` | The coordinate space you draw in |
| View size | `style` of the `Canvas` component | How large the canvas appears on screen |

The drawing is scaled to fill the view.

Without `width` and `height`, the drawing size follows the layout size of the view. The canvas is resized and redrawn when the layout changes.

## Device pixel ratio

With `enableDevicePixelRatio` (the default), the canvas renders at a higher resolution on high density screens. The ratio is `1 + (devicePixelRatio - 1) × 0.75`, the same as WebCanvas on web. Set `enableDevicePixelRatio={false}` to render at the drawing size.

## Lifecycle

- The `ref` is set before the effects of the parent component run, so a `useEffect` can create the canvas and draw right away.
- The view does not destroy the canvas. Call `destroy()` in the effect cleanup.
- To change `enableDevicePixelRatio` or `engineOption`, destroy the canvas and create a new one.

## Touch input

The `Canvas` component accepts all `View` props, including the responder props. Convert the touch position to drawing coordinates with the layout size:

```tsx
const layout = useRef({ width: 600, height: 600 });

const onTouch = (e: GestureResponderEvent) => {
  const x = e.nativeEvent.locationX * (600 / layout.current.width);
  const y = e.nativeEvent.locationY * (600 / layout.current.height);
  // ...
};

return (
  <Canvas
    ref={view}
    onLayout={(e) => {
      layout.current = e.nativeEvent.layout;
    }}
    onStartShouldSetResponder={() => true}
    onResponderGrant={onTouch}
    onResponderMove={onTouch}
  />
);
```

Inside a `ScrollView`, also pass `onResponderTerminationRequest={() => false}` so that dragging on the canvas does not scroll.

## Android backing view

On Android the canvas draws into a `TextureView` by default. It blends with the views behind it and supports transforms and rounded corners. Set `androidBackingView="SurfaceView"` to draw into a `SurfaceView`, which composites on its own layer and does not blend with views behind it.
