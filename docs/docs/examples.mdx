The example app ports the [ThorVG Playground](https://github.com/thorvg/thorvg.web/tree/main/apps/playground) examples to React Native. Every example is a complete component that you can copy into a `.tsx` file. Open an example and tap **Show code** to see its source.

The app on this page is the web build of the same code that runs on Android and iOS.
