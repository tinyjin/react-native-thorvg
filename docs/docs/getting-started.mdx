`@thorvg/react-native-thorvg` brings [ThorVG](https://github.com/thorvg/thorvg) vector graphics and Lottie to React Native on Android, iOS and web.

It offers two APIs. The components draw declaratively with JSX. The [`@thorvg/webcanvas`](https://www.npmjs.com/package/@thorvg/webcanvas) API draws imperatively. On web the package runs `@thorvg/webcanvas` itself. On Android and iOS the same classes run on the native ThorVG engine through JSI, so the same code draws the same result on every platform.

## Requirements

- React Native with the New Architecture
- Android API 24+ and iOS 15.1+
- Expo apps need a development build (`npx expo prebuild` or `npx expo run:android|ios`). Expo Go does not include the native module.

## Installation

```sh
npm install @thorvg/react-native-thorvg
cd ios && pod install
```

With Expo:

```sh
npx expo install @thorvg/react-native-thorvg
npx expo prebuild
```

## Your first canvas

```tsx
import { Canvas, Rect } from '@thorvg/react-native-thorvg';

const Example = () => (
  <Canvas width={200} height={160}>
    <Rect
      x={20}
      y={20}
      width={160}
      height={120}
      rx={16}
      ry={16}
      fill="#2563eb"
    />
  </Canvas>
);

export default Example;
```

The [components](./components/overview) draw without any setup. `Canvas` initializes ThorVG and draws its children in order.

The same drawing with the [WebCanvas API](./guides/canvas):

```tsx
import { useEffect, useRef } from 'react';
import { Canvas, useThorVG } from '@thorvg/react-native-thorvg';

const Example = () => {
  const TVG = useThorVG();
  const view = useRef<Canvas>(null);

  useEffect(() => {
    if (!TVG) return;
    const canvas = new TVG.Canvas(view, { width: 200, height: 160 });

    const shape = new TVG.Shape();
    shape
      .appendRect(20, 20, 160, 120, { rx: 16, ry: 16 })
      .fill(37, 99, 235, 255);
    canvas.add(shape).render();

    return () => canvas.destroy();
  }, [TVG]);

  return <Canvas ref={view} style={{ width: 200, height: 160 }} />;
};
```

`useThorVG()` returns `null` until ThorVG is ready and then the ThorVG namespace (`TVG`). `new TVG.Canvas(view, options)` creates a WebCanvas `Canvas` on the view, with the same methods such as `add`, `update` and `render`. Both can be combined through [refs](./components/overview#refs).
