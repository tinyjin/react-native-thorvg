# Docs

The documentation site for `@thorvg/react-native-thorvg`, built with [Docusaurus](https://docusaurus.io).

```sh
yarn docs                 # from the repository root, starts a dev server
yarn workspace @thorvg/react-native-thorvg-docs build
```

`build` also exports the example app for web into `static/examples`, which the Examples page embeds.
